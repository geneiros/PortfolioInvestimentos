Define uma palavra-passe primeiro

Estás a abrir a aplicação a partir de outro dispositivo. Para proteger os teus dados financeiros, o acesso fora do computador onde a aplicação corre só é permitido com palavra-passe.

Define-a de uma destas formas e recarrega a página:

  • no computador onde a aplicação corre, em Definições → Segurança;
  • na variável de ambiente PORTFOLIO_PASSWORD do servidor (ex.: na cloud).
